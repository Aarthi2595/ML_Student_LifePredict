# Dataset folder

Place the original Kaggle file here, **unchanged**:

    data/student_lifestyle_dataset.csv

Expected columns: `Student_ID, Study_Hours_Per_Day, Extracurricular_Hours_Per_Day,
Sleep_Hours_Per_Day, Social_Hours_Per_Day, Physical_Activity_Hours_Per_Day, GPA, Stress_Level`
(2,000 rows). Check the dataset's licence on Kaggle before committing it to a public repository.
